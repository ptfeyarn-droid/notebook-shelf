# Notebook Shelf

Notebook Shelf は、開発者本人が個人利用のために開発したツールです。

Google の Gemini Notebook 公式 API を使い、開発者本人が収集した資料（Web ページの URL やテキスト）を、本人自身の Gemini Notebook のノートブックへ登録します。

## 利用者について

- 利用者は開発者本人 1 名のみです
- 第三者への提供・公開はしていません

## 機能

- ノートブックの作成と一覧取得
- ノートブックへのソース（URL / テキスト）の追加
- 追加したソースの状態確認
